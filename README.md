# MediCare Billing System

Java-based client-server billing system for healthcare facility.

## Project Overview

This project implements a multi-threaded client-server application for processing patient billing in a healthcare setting. The system uses Socket programming for network communication, JDBC for database operations, and Java Collections Framework for data management.

## Features

- Multi-threaded Architecture: Server handles multiple client requests concurrently
- Socket-based Communication: Client-server communication on port 5000
- Database Integration: Apache Derby database with JDBC connectivity
- Billing Calculations: Automated billing based on insurance plans and patient types
- Collections Framework: HashMap-based utility for managing billing records

## Technologies Used

- Java 25
- Apache Derby Database
- Socket Programming (java.net)
- JDBC (java.sql)
- Collections Framework (java.util)
- Multi-threading (Runnable interface)

## Files

- BillingClient.java - Client-side application
- BillingServer.java - Server-side application
- PatientBillingUtility.java - Collections utility class
